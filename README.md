# MD.Portfolio

A responsive, accessible six-page static portfolio website for MD Ilful Hossain. It uses plain HTML, CSS and JavaScript and can be opened directly in a browser or published on any static web host.

## Pages

- `index.html` — Home
- `projects.html` — Projects
- `about.html` — About me
- `skills.html` — Skills
- `experience.html` — Experience
- `contact.html` — Contact

## Run locally

Open `index.html` in a browser, or serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features demonstrated

- Responsive layouts with CSS media queries
- Keyboard-friendly navigation, skip link, visible focus styles and semantic headings
- Light/dark theme toggle saved in local storage
- Language picker with English, te reo Māori, Hindi, Bengali, Chinese, Spanish, French and Japanese labels
- Local portfolio chatbot implemented with JavaScript and DOM events
- Project cards with links to live work and GitHub
- Reduced-motion support for users who prefer less animation
- All website pictures and animated GIFs stored in the dedicated `images/` folder
